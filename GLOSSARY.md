# Personal Todo List

This context covers a personal app for recording tasks and keeping track of which ones are complete.

## Language

**할 일**:
A single item the user intends to remember and do.
_Avoid_: 작업, TODO

**완료 상태**:
The state the user marks when a 할 일 is finished.
_Avoid_: 체크 여부

**남은 할 일**:
A 할 일 that has not been marked complete.
_Avoid_: 미완료 작업
