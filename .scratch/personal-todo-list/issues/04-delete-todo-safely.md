# 04: 확인 후 할 일 삭제

**What to build:** 사용자가 미완료 또는 완료된 할 일을 실수 없이 삭제하고, 삭제 결과가 목록과 남은 할 일 개수에 반영되게 합니다.

**Blocked by:** 03: 할 일 완료 상태 관리

**Status:** done

- [x] 삭제를 요청하면 앱 안의 확인 대화상자가 열립니다.
- [x] 취소하면 할 일은 그대로 남습니다.
- [x] 삭제를 확인하면 선택한 할 일은 영구 삭제되고 새로고침 후에도 다시 나타나지 않습니다.
- [x] 미완료 할 일을 삭제하면 남은 할 일 개수가 즉시 갱신됩니다.
- [x] 완료 여부와 관계없이 삭제 확인, 취소, 삭제 결과를 화면에서 검증합니다.
