# 05: 저장 문제 안내 및 복구

**What to build:** 브라우저 저장 공간을 읽거나 쓸 수 없을 때 사용자가 문제를 이해하고, 저장된 할 일이 사라진 것처럼 오해하지 않게 합니다.

**Blocked by:** 04: 확인 후 할 일 삭제

**Status:** done

- [x] 저장된 할 일을 읽지 못하면 빈 목록인 것처럼 가장하지 않고 명확한 안내를 표시합니다.
- [x] 읽기 실패 후 사용자는 다시 불러오기를 시도할 수 있습니다.
- [x] 추가, 완료 상태 변경, 삭제 중 저장이 실패하면 실패 안내를 표시하고 성공한 것처럼 화면 상태를 바꾸지 않습니다.
- [x] 저장 오류 상황은 화면에서 확인 가능한 흐름으로 검증합니다.
