# 02: 할 일 추가 및 저장

**What to build:** 사용자가 빈 목록에서 제목으로 할 일을 추가하고, 추가한 할 일을 같은 브라우저에서 다시 볼 수 있게 합니다.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 한국어 반응형 화면은 처음에 빈 상태와 남은 할 일 0개를 보여줍니다.
- [x] 사용자는 추가 버튼이나 Enter로 할 일을 추가할 수 있고, 추가 후 입력창이 비워집니다.
- [x] 제목 앞뒤 공백은 제거되고, 빈 제목은 안내와 함께 거부되며, 같은 제목의 할 일도 추가할 수 있습니다.
- [x] 추가한 할 일은 새로고침 후에도 같은 브라우저에 남고 남은 할 일 개수에 반영됩니다.
- [x] 저장 접근은 한 경계에 모여 있으며, 화면에서 확인 가능한 흐름으로 동작을 검증합니다.
